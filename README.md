
# 📚 FocoEstudos — ENEM & PAS-UEM

Uma plataforma web estática desenvolvida para auxiliar estudantes na organização da rotina de estudos para o **ENEM** e **PAS-UEM**.

## 🚀 Funcionalidades

- **Visão Geral das Provas:** Informações sobre o ENEM e a avaliação seriada do PAS-UEM.
- **Grade de Conteúdos:** Lista organizada de tópicos frequentes por disciplina.
- **Guia de Redação:** Estrutura e competências exigidas.
- **Cronograma Semanal:** Sugestão de divisão diária de matérias.
- **Timer Pomodoro Integrado:** Ferramenta interativa de gerenciamento de tempo com alertas sonoros e contador de ciclos.
- **Design Responsivo:** Adaptado para navegação em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox, CSS Grid e CSS Variables)
- **JavaScript (Vanilla JS)**
